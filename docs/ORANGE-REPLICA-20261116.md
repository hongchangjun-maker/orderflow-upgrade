# 원본 보존형 주황 복제본 — 2026-11-16

## 범위와 완료 판정

원본 사이트에 수정 요청을 보내지 않고 공개 배포된 관리 화면 코드와 CSS를 내려받아 별도 앱 안에 재구성했다. 원본 DB·인증정보·고객·주문은 복사하지 않았다. 원본과 동일한 **화면 코드 보존**이며, 비공개 서버 전체를 복제했다는 뜻은 아니다. 실제 신규 고객 주문서는 기존 독립 ORDERFLOW 경로에 보존된다.

- `/` → `/replica`: 원본형 주황 관리 화면, 로그인 없는 브라우저 전용 시험판
- `/overview`: 이전 고급형 소개 화면 보존
- `/admin`: 이전 가상 운영 시뮬레이션 보존
- `/admin/secure`: 기존 실제 관리자 인증 보존
- `/order/fresh-market`: 기존 독립 앱 고객 주문서 보존

## 근거와 제한

- 캡처 원본 JS SHA256: `fc48b6f9798201f29a16e53f78638c2b6bcd8a6fca07b94d26067d4ca339704c`
- REA 전체 번들 분석은 1.5GB 분석 힙 한계로 중단되었다. Evidence `ev_cd9c2c3b1069346c8690f62d5a9418516afcf211782e1cb40c933af7660bf4f2`; 전체 분석 완료로 간주하지 않는다.
- 정확한 UTF16 오프셋으로 추출한 16,822byte의 메뉴·라우팅·대시보드 관련 자료는 REA에서 파싱 성공: 2,779 AST 노드, 93 정적 발견. Evidence `ev_3c4290070c108b1cc5b946f0968856e7fca5c23f5350ffb4d8e113873027a8db`. 미해결 참조가 있으며 정적 분석은 실행 증거가 아니다.
- 원본 라우트 레지스트리 47개와 메뉴/탭/주문 그리드/제작 화면 코드를 유지한다. 원본 자체가 준비중인 8개 경로도 그대로 보존한다.
- 변경점은 주황 팔레트, `/replica` basename, 격리된 저장소·Axios 어댑터, 실시간 네트워크·알림 권한 요청 제거, 시험판 안내와 모바일 메뉴다.

## 실제 확인한 것

- 원본 로그인 화면을 읽기 전용으로 확인; 대시보드, 주문 검색·상세검색 동선 확인 후 원래 대시보드로 복귀. 저장·전송·발행·삭제를 실행하지 않음.
- 데스크톱에서 원본과 같은 메뉴·빠른메뉴·요약 카드 구조 및 주황 브랜드 확인.
- 30개 주요 일반 화면(대시보드 포함)을 순회. 시험 응답 계약 오류로 화면이 비던 할일관리·사용료·문의·채팅을 수정하고 재확인.
- 가상 주문 1,000건 생성, 1,000건 목록/가상화, 특정 고객 1건 검색, 우클릭 처리 메뉴, 포장 상태 변경 확인.
- 390px 요청의 브라우저 viewport는 실행 환경에서 488px로 관측됨. 390px 실기기 검증 완료로 표시하지 않음.
- 자동 테스트: 기존 도메인 11개, 복제본 3개, 렌더링/보존 계약 5개. 타입·lint·빌드 별도 검사.

## 보안과 데이터 책임

브라우저 요청은 로컬 어댑터에서만 처리한다. Worker에서 복제본 문서에 `connect-src 'none'`, `form-action 'none'` CSP를 강제한다. 가짜 토큰은 서버가 인정하지 않는 단순 로컬 실행 표식이다. 원본 localStorage 키를 그대로 공유하지 않고 `orderflow:orange-replica:v1:`로 격리한다.

은행·문자·카카오·세금계산/현금영수증·결제·비밀번호/권한 변경을 실제로 실행하지 않는다. 미구현 변경 API는 성공 응답을 만들지 않고 명시적으로 거절한다. 일부 조회는 빈 시험 데이터이며 서버 동작 동등성을 주장하지 않는다. 고객·상품·주문서 저장 전체 계약, 주문 병합, 배송 최적화, 실시간 고객 채팅, 외부 공급자 연동, 다중 사업자 테넌트 권한, 실제 동시 HTTP 부하는 후속 구현·검증 대상이다.
